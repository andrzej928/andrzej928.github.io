⚙ Połączenie z GitHub

Zapis działa przez API GitHuba – zmiany trafiają jako commit do pliku data/config.json, a GitHub Pages publikuje je zwykle w ciągu 1–2 minut.
Token utworzysz w GitHub → Settings → Developer settings → Fine-grained tokens: dostęp tylko do tego repozytorium, uprawnienie Contents: Read and write. Bez tokenu możesz edytować i pobrać plik JSON, a potem wrzucić go ręcznie.
